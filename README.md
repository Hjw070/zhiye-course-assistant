# 知页 · 课程资料问答助手

高级组主题：**跨域知识探索**。这是一个课程作业的最小可运行原型：把课程笔记导入资料库，输入问题，返回相关原文及文件名、行号；也可连接兼容的模型接口，根据检索资料生成回答。

- [在线体验（无需登录）](https://zhiye-course-hjw070.ableboot18.chatgpt.site/)
- [70 秒演示视频（无需登录）](https://zhiye-course-hjw070.ableboot18.chatgpt.site/video.html)
- [GitHub 源码仓库](https://github.com/Hjw070/zhiye-course-assistant)

浏览器版在本机内存中处理导入资料，提供离线检索、原文与行号、问答导出。桌面版另支持可选模型接口。

## 快速运行

安装带有 Tkinter 的 Python 3.10 或更新版本。在本目录打开终端运行：

```console
python app.py
```

Windows 用户可双击 `启动知页.bat`。**无需 pip 安装依赖，默认不需要联网，也不需要 API Key。** 若提示没有 tkinter，请安装带 Tcl/Tk 组件的 Python。Linux 可通过发行版提供的 tkinter 包补齐。

启动后已加载两份自编演示资料。点击左侧的示例问题，例如“如何缓解过拟合？”，即可看到结果。

## 已实现功能

- 导入 TXT / Markdown 文件，支持 UTF-8（含 BOM）和 GB18030。
- 按段落和长度切分资料，记录来源文件和原始行号。
- 用中文双字、英文词的 TF-IDF 向量和余弦相似度检索前 3 个片段。
- 默认直接摘录原文；无足够匹配时提示未检索到相关片段。
- 在“原文与出处”页签中核对原文；导出本次会话的 Markdown 记录。
- 可选连接兼容 `chat/completions` 的模型接口；接口失败时明确标记并回退到离线摘录。

## 最短演示流程

1. 启动程序，说明这是高级组“跨域知识探索”的课程资料问答原型。
2. 点击“如何缓解过拟合？”，展示原文中的正则化、早停等方法。
3. 打开“原文与出处”，展示来源文件和对应行号。
4. 点击“什么是机会成本？”，展示另一学科的资料检索。
5. 点击“火星上有多少家咖啡馆？”，展示无匹配提示。
6. 导入 `examples/我的课程笔记.txt`，提问“番茄种植需要什么？”，最后导出会话。

## 可选大模型模式

在程序中点击“配置可选模型接口”，填入服务商提供的接口基础地址、模型名称和 API Key，再勾选“使用大模型组织回答”。基础地址需要包含服务商规定的路径前缀，例如 `/v1`；程序自动追加 `/chat/completions`，也可填写完整端点。

也支持读取 `ZHIYE_API_BASE`、`ZHIYE_MODEL`、`ZHIYE_API_KEY` 环境变量。模型默认不会启用，需自行勾选。公网接口必须使用 HTTPS；本机 `localhost` / `127.0.0.1` / `::1` 的 HTTP 接口可用于本地模型。不要把真实密钥写入仓库。

启用后会把**问题和检索到的片段**发送到你配置的接口；本次通过窗口输入的密钥只保存在进程内存。导出内容不含密钥，但含问题、回答和资料原文，请自行选择适合公开的资料。

## 实现说明

```text
TXT / MD → 保留行号分块 → TF-IDF 检索 → 原文摘录（默认）
                                  └→ 资料 + 问题 → 可选模型 → 回答
```

`core.py` 负责分块、编码读取、检索、接口调用及导出格式；`app.py` 提供 Tkinter 窗口。模型请求放在线程中执行，使用队列回传结果，避免网络等待阻塞窗口。

## 验证

```console
python -m unittest discover -s tests -v
```

测试覆盖中文问题命中、来源行号、未知问题、导入和更新、长行分块、文本编码和大小限制、本地模拟服务上的模型请求协议，以及窗口中的“导入→提问→导出”流程和接口失败回退。窗口集成测试使用预定路径替代系统文件选择框，需要 Tk 图形环境。**模拟接口验证不等于真实商业模型效果评测。** 未使用真实付费模型进行效果评测。

## 范围与限制

这是最小原型，没有账户、云同步、多轮对话、向量模型或持久化资料库。关闭程序后，新导入资料和会话不保留；需要保留的会话请手动导出。演示资料会在下次启动时重新加载。

单份文件上限 1 MB，资料总量上限 300 万字符。暂不支持 PDF、Word、OCR 或网页抓取。关键词检索对同义改写、单字查询和复杂推理的支持较弱；相似度阈值 0.10 是经验设置，不是可靠性保证。无匹配只表示当前检索未命中。

**默认离线模式是检索和原文摘录，不等同于大模型生成或完整 RAG。** 接口模式才把检索与生成串联起来；即便回答带来源，也应核对原文。
