项目名称：知页——课程资料问答助手

项目介绍：

知页面向课程笔记分散、查找知识点费时的问题，提供可追溯的资料问答入口。用户可导入 TXT 或 Markdown 资料，输入问题后，系统通过文本分块与 TF-IDF 检索返回相关原文，并显示文件名和行号，便于核对依据。支持跨学科概念检索、问答记录导出，在未匹配到足够相关资料时明确提示。浏览器版无需登录或 API Key，资料只在本页内存中处理；Python 桌面版另支持配置兼容模型接口，根据检索资料组织回答。项目附自编演示资料与 70 秒演示视频，可直接体验。

项目主题：跨域知识探索
